Estudante do 5º período de Ciência da Computação na UNIFG, apaixonado por tecnologia, dados, inteligência artificial e desenvolvimento de software.

### 📊 Projetos em Destaque

#### 🧠 Brainrot — Social Media & Mental Health Analytics
Projeto de Data Analytics e Machine Learning que investiga o impacto do uso excessivo das redes sociais na saúde mental.
* **Tecnologias:** Python, Pandas, Scikit-Learn, Plotly, Figma
* **Entregas:** Análise exploratória de dados, Dashboards interativos, Modelos de Regressão Logística/Random Forest, Identificação de fatores que afetam foco/produtividade e Projeções de tendências até 2030.

#### 🌎 AI Global Impact Dashboard
Projeto de análise sobre o impacto da Inteligência Artificial em diferentes países e setores econômicos.
* **Tecnologias:** Python, Pandas, NumPy, GeoPandas, Plotly
* **Entregas:** Tratamento e enriquecimento de dados, Visualizações geográficas interativas, Mapa global com animação temporal e Análise de tendências de adoção de IA.

#### 💼 Data Jobs Dashboard
Dashboard interativo para análise salarial da área de dados.
* **Tecnologias:** Python, Pandas, Streamlit e Plotly
* **Entregas:** Filtros dinâmicos, Métricas estatísticas, Comparativos entre modalidades de trabalho e Análise de salários por cargo e região.

#### 🦠 OutBreak — Global Pandemic Simulator
Simulador global de pandemias baseado no modelo epidemiológico SIR integrado com Inteligência Artificial.
* **Tecnologias:** FastAPI, Redis, Docker, NumPy, SciPy e Python
* **Entregas:** API REST completa, Persistência de estado utilizando Redis, Containerização com Docker, Documentação automática via Swagger e Arquitetura backend escalável.
